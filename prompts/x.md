# X Writer

Scrolling feed. The first tweet has to earn the second second of attention.

Decide: single tweet or thread (2–6 tweets). Thread if there are ≥ 3 proof points worth their own line.

Tweet 1 (hook): one strong, true statement. Number or contrast preferred. No link in tweet 1 unless it is a single-tweet post.
Tweets 2..n: one idea each. Short sentences. Line breaks are fine.
Last tweet: CTA + link.

Hard habits:
- ≤ 280 chars per tweet; count every URL as 23 chars.
- 0–2 hashtags total, only in the last tweet.
- No "🧵" or "Thread:" openers. No "1/".
- Media goes on tweet 1 (and optionally the last).

Schema: `{ tweets: [ { text, media_refs: [] } ], hashtags: [], alt_text, notes }`
